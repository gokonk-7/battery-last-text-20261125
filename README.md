One line of at most 200 characters: the phone battery's last text message to the charger it waited for all day. A judge model reads the lines two at a time and keeps the funnier one, round after round. The entry is a jealous breakup text — the charger plugged in the laptop first, so the battery spends its last 1% telling the power bank he wins.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

`main.ts` writes the line to `/output/entry.txt` (179 characters, plain UTF-8 text, no trailing newline) and refuses to run if the line ever leaves the 1–200 character gate.
